# v0.1.0 Clean-Machine Validation

**Validated:** 2026-08-12  
**Revision:** `c21388c` (`main` after PR #23)

This validation used a fresh clone with a separate `uv` cache and virtual
environment. It did not use the development checkout's `.venv` or
`video-mcp.yaml`; generated artifacts were written to the isolated checkout.

## Results

- `uv sync --locked --dev` installed the locked dependencies into the fresh
  environment.
- `video-mcp --version` reported `0.1.0`.
- The isolated test suite passed: **88 passed**.
- `video-mcp doctor` reported the core caption pipeline, FFmpeg/FFprobe,
  Whisper.cpp/model, Kdenlive, MLT/melt, and workspace ready.
- `scripts/smoke_test.py --config video-mcp.example.yaml` created its source,
  WAV, transcript, SRT, ASS, and preview artifacts successfully.
- The real 19-second recording completed the CPU Whisper caption pipeline,
  producing a normalized transcript, SRT, ASS, and preview in the isolated
  artifact directory.
- `video-mcp kdenlive` created a separate editable `.kdenlive` project and
  copied/linkable SRT from those generated artifacts.

## Optional backend note

The example configuration intentionally leaves local LLM cleanup disabled, so
the clean run used deterministic cleanup. Optional CUDA, Parakeet, and local
LLM runtime checks remain documented separately and are not release blockers.
